# Vigyan Darshan / विज्ञान दर्शन

This update edits the existing buildless bilingual study site. It retains the custom Canvas engine, the 44 scene modules, all 12 Science chapters and the `vigyan-darshan-v3` localStorage key. No runtime dependencies, Three.js or CDN assets are used.

Existing site: https://ujjval-science-nine-lab.speedycarp20.chatgpt.site . The included `.openai/hosting.json` retains this project identity for future updates.

## Run

Serve `dist/` using a static HTTP server. For example, on your own computer:

```sh
python3 -m http.server 8080 --directory dist
```

Open `http://localhost:8080`. ES modules and JSON need HTTP rather than `file://`. Service-worker offline use needs HTTPS or localhost; wait for the footer to confirm the offline book is ready before disconnecting.

## Build and check

Node.js 20+ is sufficient; no installation is needed.

```sh
npm run build
npm test
grep -P '[०-९]' dist/data/chapters.json
```

For the last command, exit code 1 with no output means no Devanagari numerals were found. Run `node scripts/build-offline.mjs` after any public-file change. It regenerates the class catalogue and service-worker cache version.

## Class data

`dist/data/class-9.json` is the canonical Class 9 payload: metadata, planned subjects and the full `chapters` array. All other classes have their own small `class-lkg.json`, `class-ukg.json`, and `class-1.json` through `class-12.json` files, currently with empty chapter arrays. Empty classes show a Coming Soon card with planned subjects. No lessons were invented for the other classes.

`dist/data/classes.json` is generated by scanning `class-*.json`. To add class content later, fill its JSON or drop in a correctly shaped class file, run `node scripts/build-offline.mjs`, and publish. No application code change is needed. Populated class chapters should follow the Class 9 chapter schema. Subjects shown in placeholders are planned study categories, not official stream-enrolment rules.

```json
{
  "id": "5",
  "title": {"en": "Class 5", "hi": "कक्षा 5"},
  "subjects": [{"en": "Science", "hi": "विज्ञान"}],
  "chapters": []
}
```

`dist/data/chapters.json` remains a generated compatibility export for existing source consumers and the explicitly requested legacy-path grep check. The new app does not load it, and the offline cache does not download the duplicate. Both class payload and compatibility export come from the same content source.

## Scene learning flow

Every scene has two attainable missions, an array of value-dependent live guidance, its existing scientific explanation and real-life connection, and an instant-feedback Quick Check. All controls are unlocked. A mission stays ticked after its target has been reached. Quick Check appears after a range control has changed once; choosing a selector alone does not unlock it.

```json
{
  "missions": [
    {"id":"slow", "label":{"en":"Set energy to 0.5×","hi":"ऊर्जा 0.5× रखें"},
     "when":{"control":0,"op":"eq","value":0.5}}
  ],
  "liveText": [
    {"when":{"control":0,"op":"lte","value":1},
     "text":{"en":"Lower energy means slower average motion.","hi":"कम ऊर्जा पर औसत गति धीमी होती है।"}}
  ]
}
```

Conditions support `eq`, `lt`, `lte`, `gt`, `gte`, and optional `selector` instead of `control`. The first matching `liveText` item is used. `prediction.reason` is retained as the explanation behind the Why button, not as a prediction form or lock.

## Renderer and controls

- Final toolbar: Play/Pause, Restart, Reset view, Show labels.
- Drag, pinch, wheel and keyboard rotation/zoom remain available.
- Speed buttons: 0.25×, 0.5×, 1×, 2×. Speed multiplies simulation time; readouts and graphs use that same clock.
- Spheres use cached, shaded Canvas sprites with `brightness = 0.4 + 0.6 × max(0, dot(normal, [0.5, 1, 0.3]))`, clamped to [0.4, 1]. Particles are depth-sorted back-to-front.
- Chapter 1 Compare selects the particle scene and draws solid/liquid/gas in three simultaneous panels, sharing the energy control. Compare is absent from other chapters.
- All scenes in Chapters 7–10 have a mini-graph below the main canvas with bilingual axes/captions. Existing motion plots and energy bars are retained; other scenes use a bounded history of the stated measurement. Constant settings correctly produce a horizontal trace. Pausing stops the shared clock and graph advancement.
- A single engine and animation callback are retained across scene switches. Histories are capped at 300 samples and the sphere cache at 32 colours. Disposal clears listeners, observer, caches and renderer references.
- Reduced motion starts paused. Low power mode reduces particle counts, resolution and frame frequency.

## Settings and progress

The navbar has a manual light/dark toggle and a settings popover beside the language selector. The popover contains Low Power and 15/17/19px root-font choices. Preferences are saved on the current browser/device.

Existing progress IDs, score numbers and mistake records remain valid. Class 9 uses its original chapter keys; future classes use class-qualified keys. Old scores retain their original denominator in `scoreTotals`: an earlier 3/3 stays 3/3 rather than becoming 3/8 when quiz sets gain questions. A new equally good or better percentage replaces it with the new denominator. Each current set contains 10 questions; saved 3-question and 8-question scores retain their original denominator. Old mistakes are treated as Class 9 records, and the original first 3 Chapter 1 MCQs retain their order/content.

Sidebar SVG rings show best quiz percentage. Marking a chapter complete makes its ring full and gold. When no chapter is selected, the landing card uses the saved last chapter. The Mistake Notebook is a separate sub-tab in Practice with a count badge.

## Source structure

- `dist/index.html`, `style.css`, `js/app.js`: existing shell and SPA, upgraded in place.
- `dist/js/engine.js`: existing renderer plus shading, comparison and graph controls.
- `dist/js/scenes/`: existing 44 renderer modules, imported lazily.
- `content-part1.json`, `content-part2.json`: editable chapter content.
- `scene-copy.json`: existing scene copy plus missions/live guidance.
- `scripts/build-data.mjs`: builds Class 9 data and compatibility export.
- `scripts/build-scenes.mjs`: regenerates scene modules from the existing renderer sources.
- `scripts/build-offline.mjs`: discovers class files, hashes and precaches 71 local assets.
- `tests/`: science/content, mission coverage, class catalogue, lifecycle, speed and worker checks.

Self-hosted Inter and Noto Sans Devanagari remain bundled with their licences. Print exports notes, examples, written tests and hints without the canvas, lesson plans, homework or key-term boxes. The existing site's audience stays private. Chapter 2 content expansion waits for approval of Chapter 1.
